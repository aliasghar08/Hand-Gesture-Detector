# Security Policy

## Supported Versions

Currently, only the latest version of the application is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a priority. If you discover a vulnerability in this project, please report it privately by opening a secure issue or emailing the maintainers. Do not disclose vulnerabilities publicly until a fix has been deployed.

We will acknowledge your report within 48 hours and work with you to understand and mitigate the issue as quickly as possible.

## Data Privacy
- **Camera Usage:** This application uses the device camera for real-time inference. All camera data is processed 100% locally on the device using TensorFlow Lite.
- **Microphone/Audio:** The application uses the device speaker for TTS. It does not record audio.
- **No Telemetry:** No personal data, camera frames, or usage statistics are transmitted to external servers.
